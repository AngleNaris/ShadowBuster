# 母带强度重构与响度验证（2026-09-11）

## 语义

`style_blend` 为兼容旧 GUI/CLI/API 保留的参数名，现控制处理力度，不再代表整条音频干湿混合。100% 不再承诺旧引擎位级一致。前三个上游环节指高频/低频/声场处理，不是原始母带引擎自己的 step 1–3。

- 参考频谱只作平滑、有限校正，随强度变化；Mid 上限 ±1.25 dB、Side ±0.75 dB，并同时限制差分 EQ ≤0.3 dB × 强度。最终实际 Mid 上限可能因差分预算更小。
- RMS 匹配最大 ±0.25 dB × 强度；后续电平校正使用同一立体声增益，最大 ±0.25 dB × 强度。
- 风格声场处理相对输入的 M/S 比限制在 ±0.35 dB × 强度。用户显式 EQ 独立执行，不属于风格预算。
- 新动态预设为人工设定的保守起点，不声称是从原有流派模型训练出的动态参数；使用立体声联动的软拐点增益衰减与有限饱和。
- 移除生产路径的末端干湿相加、默认 18 kHz 低通、旧双重响度倍率、固定硬削波和向上峰值归一。
- 流派参考生成函数返回真实采样率；进入引擎前重采样，并保留有效带宽，缺失的参考高频不作为削减目标。
- 无风格和风格化共用 LUFS/真峰值收敛。loud 从 profile +1.58 改为 +2.50 LU，Pop 目标约 −6.70 LUFS；loud 限幅释放上限 80 ms，其他档不变。设置增益衰减预算，不能安全达标时输出实际原因，不无限压缩。

## 最终防发闷与强度连续性复验

最终 canonical 源码同步到开发、CPU stage 与 GPU stage 后，重新输出到 `D:/_4.Projects/_MY/造梦双子星2/mastering_v2_style_audit_20260911/final_guard/`。统一使用 4096 点 Hann 帧、2048 点步长，在无风格基准宽频能量前 80% 的活跃窗中比较 250 Hz–2 kHz 主体与 4–16 kHz 高频；另以基准高频能量正向跃升的前 10% 作为高频瞬态窗。

| 对照 | 活跃窗亮度 1% | 5% | 中位 | 高频瞬态 5% | 高频瞬态中位 |

直母带 off、Pop50、Pop100 分别为 −6.769、−6.764、−6.776 LUFS，4× 近似真峰值分别为 −0.457、−0.459、−0.459 dBTP。完整流水线 Pop50 为 −6.776 LUFS、−0.421 dBTP。全部达到 loud 目标与真峰值上限。

强度也具有连续性：Pop50 相对 off 的逐窗频带变化几乎是 Pop100 的一半，亮度中点误差中位仅 0.0047 dB；40 Hz–16 kHz 各主要频带中点误差中位均不超过 0.013 dB（16–20 kHz 为 0.062 dB）。完整流水线旁车显示最终 FIR 的 Mid/Side 高频相对主体分别为 +0.224/+0.129 dB，暗化保护器均为 0，说明此真实素材本身没有请求发闷修正；保护器用于阻止其它暗参考的过量主体提升。

历史 `version4` Pop50 的活跃窗亮度中位约 −6.12 dB，与上述最终结果不是同一算法。旧文件未覆盖。数值测量证明最终链路没有复现该缺陷，但不以自动指标替代人工听音验收。完整机器可读结果见 `final_guard/final_style_metrics.json`。
