## 使用方式

添加歌曲，在文件列表上方点击「草稿」自动准备，准备中可再次点击取消，就绪后播放。默认全曲播放，可拖拽进度、原声对比（不是等响对比）并边听边调。播放器固定在内容区顶部。播放器内可拖选循环；双击循环带编辑精确起止时间，拖出区间时退出循环。预览 Tab 已并入播放器，不显示歌曲名或试听频谱。仅支持无风格和用户提供参考，不增加预置参考音频。

## 近似范围

低频、饱和、鼓力度、瞬态、人声增益、吉他、声场、宽度、EQ、参考强度和响度档位可在播放期间调整。降噪只以高频衰减近似方向，人声不实时重复完整参照平衡；参考由整曲分析投影至七段音色滤波。最终响度、限幅、保护和瞬态处理不与导出等价。草稿不能用于验收最终 LUFS、真峰值或质量报告。

前端每 50 ms 发送变化的参数，标量约 30 ms 平滑；这不是实测的端到端延迟承诺。草稿不生成新的成品文件，也不替换成品波形。

## 缓存边界

移动选段、改变 EQ/母带强度/后处理旋钮不重新执行 AI；更换参考仅需参考分析。重新启动后磁盘缓存仍可复用。重建引导、吉他和重建旁路实时调整，不重新推理。GUI 固定六轨，原曲与纯重建端点分别缓存；正式导出按同样结构混合。重建精度、权重或相关阶段代码改变时，受影响缓存失效；删除或损坏缓存也需重算。

当前仍会读取、校验和复制整曲缓存，长曲准备耗时不能由短片段测试外推。进程内准备串行；不承诺多个独立应用进程同时启动时绝不重复推理。

真实测试发现 FLOAT WAV 的 PEAK 块可能含写入时间，因此连同重建强度混合产物一起缓存，避免音频相同但文件哈希改变而重复分轨。
