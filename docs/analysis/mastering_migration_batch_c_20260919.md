# 母带迁移批次 C：用户参考与最终声场

日期：2026-09-19。范围：无风格、用户 EQ、用户提供参考。用户尚无可分发参考，未添加预置参考。开发文档作为设计依据，不作为额外执行授权。

## 实现

- `mastering/matchering_adapter.py` 固定 Matchering 2.0.6 公共 API；按真实采样率解码，再统一到 44.1 kHz。中间候选为 FLOAT，关闭上游 limiter/normalize，不直接作为成品。
- 原始输入与参考用于分析，候选/原始输入的频谱比去除整体增益、平滑并限制到 ±3 dB。强度作用于滤波器 dB；共同 L/R、2049 taps 居中 FIR 作用于修复后混音，不叠加候选波形，不继承其采样偏移或 M/S 增益。参考缺失带宽不作为削减高频的依据。
- 用户 EQ 独立实现，位于参考之后。分轨降噪/去拥挤保持原阶段；最终宽度改为对当前混音处理，新增 Side 在 120 Hz 以下为零、120–240 Hz 渐入，保留原有低频 Side。无 Side 不制造声场。
- 共用自有 finalizer、应用固定响度档、−0.4 dBTP 上限和 PCM24 单次抖动量化。响度不足时如实报告，不强压动态以凑目标。
- 兼容入口、GUI 现有调用、CLI、取消、缓存与旁车接通。CLI 单独提供 reference 自动进入参考模式；显式 off 忽略参考。Matchering 已安装到开发音频解释器，Windows/macOS 装配脚本固定版本。

## 保护策略与限制

匹配前后 Side/Mid 改变量限制 −0.5 至 +1 dB；分频宽度变化 ≤0.035；相关性下降 ≤0.05；mono fold-down 损失增加 ≤0.5 dB；crest 下降 ≤1 dB；有效频段相对能量变化 ≤3.5 dB。按请求强度、1/2、1/4、1/8 尝试，不通过则原样进入无参考终段。最终限幅后再次对照同 EQ/声场/响度的无参考基线，不通过则采用基线成品。

这些值是保守工程起点，不是已完成试听标定的质量保证。有限减半和最终回退使实际采用量可能不随请求强度单调增加；报告同时记录 requested/accepted strength、每次拒绝原因和最终检查指标。最终检查的 before/after 描述候选对比，fallback 成品实际指标以顶层/readback 和 quality 报告为准。

静音、过短、不支持声道等参考回退并记录原因；缺失文件或依赖不隐式回退旧引擎。参考分析上限 15 分钟；长曲峰值内存尚未测量。原始曲线仅减少对上游调整的反向抵消，不代表所有低频/人声效果都已通过听感验证。

## 用户反馈修正：全局 EQ 与强度核验

后端 `stage_soren` 在显式 off 模式下曾过滤用户 EQ/低通参数，GUI 通过 eq_only 绕过，但 CLI/API 行为不一致。已移除这一过滤，使无参考与有参考均通过共同用户 EQ。没有修改整个母带旁路的含义。

新增参数传递与真实音频验证：off/eq_only/参考零强度/参考正常强度均传入 EQ；无参考、零强度、匹配接受、参考拒绝的最终音频均呈现 Bright 高频提升；最终保护拒绝的输出与相同 Bright EQ 的无参考基线一致。实际 Matchering 与母带子进程在请求 0/.25/.5/.75 时分别采用相同强度，写盘后 11–16 kHz 相对 0.5–1.5 kHz 能量比逐步增强（每相邻档差 >0.03 dB）。该用例确认强度接线及实际输出有效，不撤销真实素材触发保护时会减弱/回退的限制。
