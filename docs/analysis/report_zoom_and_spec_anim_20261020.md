## 起因

用户反馈三处：
1. 报告页的频率响应曲线支持缩放，交互没必要，读图口径应该只有一个；
2. 「频谱变化」区域的动画观感不对，除淡入淡出外的动画都应移除；
3. 第一次切到报告界面时，该区域不显示正确的图形（真实位图到位后
   仍显示「处理完成后可见逐格变化」占位提示）。

## 行为与接口

- **曲线视野固定**：删除整段缩放/平移交互（wheel / pointer 拖拽 /
  dblclick 复位），绘图与刻度改读常量 `RP_F_MIN = 20`、
  `RP_F_MAX = 20000`。定义域外的频点记 `null` 断线，不钳到画布边缘
  （否则两端会画出假垂直线）。`clampZoom` / `setView` / `rpZoom` 状态
  全部退役，只留 `attachRpTip` 挂 hover 读数。
- **频谱变化区只保留淡入淡出**：
  - `drawSpecBitmap(canvas, off, fHi, duration, note)` 去掉动画参数、
    `rpClipAt` 左右擦除与旧位图 `fadeFrom` 叠化，一次性画终态；
  - `renderSpectral()` 不再登记重放钩子，静态重绘（缩放窗口、换主题）
    与入场重放都不会再改写这一格；
  - 仅存的动画是三处 dissolve（`rpSpecFade` 快照淡出）：换视图
    （原始/处理后/变化）240ms、换成品版本 240ms、位图异步到达 260ms。
    `renderReport("morph")` 的频谱入口改走 `rpSpecFade`。
- **首入错误图形的根因**：位图是异步载荷（Qt 侧 `previewLoadOutput`
  回执）。入场重放钩子在位图尚未到达时登记，闭包捕获的是
  `off = null` 的占位画面；载荷随后经 `rpSpecFade` 画上真图后，重放帧
  与 `rpGuard` 兜底定时器（约入场后 870ms）又把登记时的占位提示重画
  回去，看起来就是「真图闪过后被盖掉」。删除该钩子后，重放不可能再
  触碰这一格，首入即真图。其余面板（KPI 数字、哑铃圆点、钻石张角、
  曲线）的重放机制不变。
- 仅前端改动；静态资源只递增 app.js 查询版本（v89 → v90），
  style.css 无变化（v94 不变）。
