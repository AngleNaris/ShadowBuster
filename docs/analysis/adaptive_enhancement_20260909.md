# 自适应增强与 EQ 语义更新

本轮保持 UI 控件及数值范围，不把 20% 降噪视为已证实主因，不改变降噪算法与默认值。变化只针对新增声场/饱和处理与母带 EQ。所有数值是保守工程起点，不代表已通过近期整批 AI 音乐的听感验收。

## 母带 EQ

`packaging/soren_original.py::apply_eq_style` 是唯一曲线实现；core 的 EQ-only 与 styled 共用同一模块。使用真正 RBJ high-shelf/low-shelf/peaking EQ，避免高通结果与原信号相加的相位缺口。

旧高架算法的独立正弦测量：4阶高通、fc=9k、混合增益1.19时，8k约-0.69dB、9k约-1.25dB、10k约-1.31dB、12k约-0.28dB、16k约+1.03dB。这是该拓扑的一组复现参数，不等于声称用户那首歌所有空气感损失都来自它。

| UI | 新EQ定义 |
|---|---|
| 平直 Neutral | EQ严格恒等；仍选流派时不代表绕过流派匹配，响度处理也独立存在 |
| 温暖 Warm | Mid 150Hz低架+1.5dB；不再削2–3k存在感，Side不额外削高频 |
| 明亮 Bright | Mid 3.2k bell +1dB、9k高架+1.5dB；Side 8k高架+1.5dB、250Hz bell -0.7dB；删除约550Hz Mid增厚 |
| 融合 Fusion | Mid 150Hz低架+0.8dB、9k高架+0.8dB；Side 8k高架+0.8dB、250Hz bell -0.26dB；不强调存在感 |

高架标注是渐近增益，截止附近不等于全量增益。叠加滤波器的总响应可能超过单段数值。融合是轻量音色折中，不表示增加压缩器或混响。EQ之后仍有动态/峰值控制，风格路径仍有既存低通；因此测试分别覆盖EQ本身与实际路径，而不承诺任意母带输入输出的每个频带必然提高。

频响测试覆盖44.1/48/96/192k采样率、中央和两侧、8–16k无反向凹陷、Neutral恒等、mono输入不产生Side、core与styled曲线逐样本一致。

## 声场自适应

现有width dB/wet控制保留，先生成请求增量，再在最终候选混音上约束Side；不替换原Mid/Side，不新增Haas延迟或全通去相关。

- 分析：4096点Hann STFT、75%重叠；短音频自适应窗口，少于32样本不新增宽度。
- 新增Side在120Hz以下为0，120–240Hz余弦平滑过渡。重建后的有限窗边界存在极小泄漏，不把它宣称为无限长砖墙滤波。
- 各带 Side能量/(Mid+Side能量)预算：120–300Hz 0.10、300–2000Hz 0.35、2–8kHz 0.55、8kHz以上0.45；相对原Side最大能量增长分别1/2/3/2dB。
- 每帧按原Side、新增Side及其互相关解二次约束，原已超过上限则不再增加；增量系数做保守跨帧平滑。上限是分析域预算而非普适审美数值，重叠重建后需保留验证容差。
- 鼓使用立体声联动4ms/70ms包络，快速起音相对慢包络超过3dB开始减少新增宽度，到12dB时最多减少75%；尾部放开。此为瞬态启发式，不是房间声分离。
- 降噪算法/强度未改，仍独立执行。它的处理差值作为预算前基底，宽度约束本身只加入反对称Side。

## 低频饱和密度约束

Sub/鼓身/瞬态旋钮与自动清晰开关均保留。只对饱和新增信号的180–500Hz分量施加最多3dB减量，不对原始人声/吉他或整个混音直接加EQ。

允许新增幅度启发式为 max(0, 0.15×原30–120Hz RMS - 0.2×原180–500Hz RMS)，与预测饱和新增量比较后得到全曲共用的静态因子，左右联动。最多3dB意味着不是保证一定达到该目标的硬预算；带通存在裙边，低频影响按测试容差衡量，不宣称120Hz以下严格零影响。

静态因子避免逐拍抽动；sat=0或预算因子1保留旧饱和路径；旋钮增加仍允许更多饱和。该约束不解决所有低频掩蔽，也未给人声自动加高架。参数需结合AI曲目盲听继续校准。
