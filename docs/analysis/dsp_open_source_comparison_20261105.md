## 当前生产路径

独立母带路径：分轨低频/鼓处理 → 去拥挤/降噪/其他分轨处理 → 卫生处理 → 参考音色（可选）→ 用户 EQ → 最终混音宽度 → ZL 多频段密度压缩 → 独立限制器/响度 → 真峰值/量化/写后测量。

## 1. 声场：范围清晰，但最终路径丢失了部分已有控制能力

`mastering/soundstage.py:32` 的 `widen` 在 120–240 Hz 做平滑过渡，高于过渡区增强现有 Side。纯单声道时返回 `no_existing_side`。它没有生成空间反射、时延去相关或新 Side，不能从该算法推导“单声道也应更宽”或“纵深得到恢复”。这不是必须修复的缺陷，是否增加空间合成应单独决定。

Calf 的 Haas 实现从选定输入取得 mid，再用两条可调时延、增益和极性组合左右输出，确实具有不同的空间生成机制。此机制也会改变音色和定位，不代表应该作为本项目默认替代。

更直接的问题是路径分离：`apollo_scripts/soundstage_reshape.py:227` 有鼓起音宽度保护，`:241` 有 4096 Hann / 75% overlap 的分带控制；独立母带把其宽度 wet 归零后，最终 `widen` 没有对应的瞬态/持续部分区分。

探针：44.1 kHz、8 秒，Mid 为 997 Hz，Side 为 2111 Hz；前 7 秒 S/M 幅度比 0.1，末 1 秒为 0.8。调用 `widen(wet=.6, width_db=6)`，局部统计取 7.1–7.9 秒避开边界。

| 相关度 | 输入 | 输出 |
| --- | --- | --- |
| 整段 | +0.8370 | +0.6308 |
| 末段 | +0.2195 | −0.2403 |

请求增量 `0.597157` 被完整接受，整曲 guard 未触发。这证明当前 guard 没有局部保证，不证明真实音乐会出现同等问题，也不把所有负相关归为损伤。后续若补局部检测，应继续遵守既有政策：保留原有负相关内容，不恢复已废弃的单声道损失或固定宽度封顶政策。

## 2. 低频：先分清增强、染色和重建

当前 `bass_enhance.py` 主要增强已有低频并产生谐波，没有显式次谐波生成、音高跟随或基音重建机制。对单一稳态正弦，奇对称 tanh 主要产生向上的奇次谐波；不能据此承诺恢复缺失的基音。复音非线性还会产生互调，因此也不能泛称它绝不会生成更低频率。

Airwindows DubSub 则含有过零翻转的次八度状态及后续低频生成/整形。它是生成新低频的对照，不是恢复原始低频真实性的证明，也不建议为解决发闷而默认增加这一层。

### 已复现：饱和旋钮同时抬升基波

`soft_clip(x, drive)=tanh(drive*x)/tanh(drive)`，小信号斜率为 `drive/tanh(drive)`。固定 drive=1.6 时大于 1，因此弱信号下的 wet 支路仍带明显线性增益。

探针使用 3 秒 60 Hz 正弦；Sub/Punch/Transient=0、sat=.3、drive=1.6；固定活动门为 1、预算因子为 1，隔离饱和支路。去除首尾各 0.5 秒，测量基波及 3/5/7/9 次谐波。

| 输入峰值 | 基波增益 | 所测奇次谐波合成量，相对输出基波 |
| --- | --- | --- |
| 0.01 | +1.7200 dB | −101.02 dB |
| 0.30 | +1.5240 dB | −42.68 dB |

这不是全链音乐 THD，也不是听感评分。它说明 sat 的作用明显依赖输入电平，弱输入下的变化主要是基波增益。当前 180–500 Hz 饱和增量预算不会直接抵消 60 Hz 基波提升。

应优先比较基波增益匹配后的染色效果，再决定是否调整归一化或驱动标定。任何改变都会影响已选预设，不能未经试听直接修正。

### 局部适应性仍有限

- 自动清晰度的频率固定为 285/800 Hz，整曲 Welch 统计后给全曲同一组 EQ。
- 饱和低中频预算使用整曲能量和固定比例，注释已说明是待听感验证的启发式。
- Kick 检测要求低频 thump 与 1–3 kHz 起音共同出现；无 click 的软底鼓/808 属于已知证据不足范围。它是避免误触发的取舍，不能简单通过降低阈值消除。
- 瞬态模块主要增强起音，没有独立的鼓身和衰减时长控制。此前用户偏好的回弹需要结合 ZL 包络和后续限制器评估。

## 3. 母带：保护较完整，音色与动态优化仍偏固定策略

当前终段不是只有归一化：真峰值、联动限制器、预读、局部介入预算、写后测量等均已存在。11 月 4 日修复也已进入当前源码，不应再次报告为缺失。

主要差距是 `finalizer.py:115` 按响度档固定选择 80 或 150 ms 释放，`linked_limiter` 使用固定的保持/线性斜坡及一阶恢复。它没有根据孤立峰、密集低频、持续音等情况选择不同恢复行为。

LSP Limiter 的源码将 ALR 和短峰整形分开，可选择 Hermite、指数或线性补丁及其时长形状。可借鉴的是不同时间尺度的增益控制；不能因模式更多就宣称它在本项目更透明。当前 ZL 密度压缩已经位于终段前，比较时必须同时保持它及总减益条件一致。

参考处理有意将 Matchering 候选投影为共享 L/R、平滑且 ±3 dB 有界的音色 FIR，丢弃候选自身相位、M/S 增益和响度。它与“直接使用完整 Matchering 成品”功能不同，是保留上游意图的设计，不应简单列为功能损失。

母带目前没有专门的频率选择性动态共振处理：四段密度压缩不等于可以独立识别和控制一个窄带共振。ZL Equalizer 可作为该方向的基准，但只有在真实素材确认问题后才有必要增加此能力。

master_me 可借鉴分工清晰的处理链，但其 README 明确面向直播/网络电台，并不定位为录制音乐自动离线母带。其自动 leveler 与本项目保留主副歌对比的目标也未必一致，故不作为整链替换建议。

## 建议优先级（待用户审核，尚未转为实施 TODO）

1. 低频饱和：分离基波电平变化与谐波变化，做增益匹配对照；同时检查短段浑浊，优先复用现有滤波和检测。
2. 母带限制器：保持现有真峰值与动态预算，比较固定释放和一种简单的双时间尺度包络，观察鼓尾音、低频失真及同响度结果。
3. 声场：先补局部时频检查与鼓起音/持续部分的对照；空间合成或单声道立体化另行决定。
4. 动态 EQ、音高跟随和次谐波生成暂列可选方向，不作为本轮必须补全的功能。

每轮仅保留少量候选，先以测量排除问题，再做同段、同步、等响试听。需要区分“听得出不同”和“稳定更喜欢”。本轮没有进行真实歌曲重渲染、整链盲听或完整测试回归，因此未宣称任何新方案已经改善音质。
