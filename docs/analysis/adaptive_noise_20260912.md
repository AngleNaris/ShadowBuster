# 第 3 批次：跨分轨高频降噪实现与验证

## 结论

新增 `adaptive_all` 实验性高级模式，默认仍为 `other` 兼容路径。已验证的内容是处理边界、旁路、分轨路由、指标与报告一致性；不是专业音质认证。真实 AI 音乐六个片段的整体高频变化极小，本次不能证明可听的沙沙声改善，不应据此切换默认模式。

## 算法与数学边界

- 对可用 vocals / drums / bass / other 以及未来可用 guitar / piano 独立分析；不会把 other 改名为 guitar，也不引入六轨分离模型。
- 默认分析范围 8–20 kHz，以约 2 kHz 子带计算谱平坦度、谱峰/均值、局部能量稳定性、谱通量、瞬态活动和与主体音乐包络的相关性。
- 每时频点抑制必须通过置信度门槛（0.55），并受谐波、瞬态、主体包络保护。算法是保守启发式，不是经过训练的噪声分类器，也不是概率校准的置信度。
- 2048 点 Hann STFT、512 点 hop；左右共用实数增益，不独立改变同一时频点的左右相位/幅度比。这不意味着任意左右异谱内容的整体声道能量比严格不变。
- 掩码衰减在 `0..amount × max_attenuation_db` 内，上限参数限制为 6 dB。时间平滑不把衰减扩散到受保护的时频点。
- 不确定、静音、过短或 amount=0 时返回原样；NaN/Inf 等非法音频显式拒绝，不输出伪造“安全”音频。
- 只将 `cleaned_stem - original_stem` 加回完整混音，保留分离残差。有限窗存在频谱泄漏，8 kHz 不是理想砖墙频率。
- 每分轨以及最终混音对降噪差值再设预算：指定 Butterworth 分频测量的全段能量不能增加、最大减少量不能超过用户上限，并且降噪差值不能提高混音采样峰值。整体宽度处理、后续母带不属于此项降噪前置预算；不能将它误称为最终 true-peak 保证。
- 谱分析按约 8 秒核心块与 1.5 秒上下文执行；完整输入与结果仍驻内存，STFT 中间数组不会随整首时长无限增长。

## 兼容与报告

`--noise-mode other` 保留旧 `_spectral_denoise()`；已用旧 Git 版本的声场脚本对比相同输入，逐样本相同。`wet=0` 只关闭拓宽，仍允许独立降噪；要使声场完全旁路还需 amount=0，或使用阶段 bypass。

高级参数：

```text
--noise-mode adaptive_all
--space-denoise 0.5
--noise-low-hz 8000
--noise-high-hz 20000
--noise-max-attenuation-db 6
```

`reshape.json` 的 `extra.noise` 记录每分轨候选处理、跳过原因、掩码统计、实际起始频率、分轨预算和混音预算。分轨 `applied` 是混音预算前的候选处理；最终是否接纳看 `noise.applied` / `mix_budget`。最终 `.quality.json` 使用 `stages.reshape.noise`，母带 `.mastering.json` 契约不变。

## 真实素材离线基准

复用已有、与声场输入对齐的分轨，不重新推理、不下载模型。素材来自本机历史处理目录 `SorenPresenceFix_20260906_184851_330919`。`drums.wav` 是声场阶段前的完整混音，不是分离鼓轨；分离轨从 `lew_stems/htdemucs/lew` 读取。

两首 AI 歌曲各取开始、中间、结尾 20 秒，共 120 秒。参数：amount=0.5，上限 6 dB（实际掩码上限 3 dB），8–20 kHz，wet=0。表格是降噪差值预算的频带能量变化，不是整首歌的噪声消除量。

| 歌曲 | 片段 | 频带能量变化 dB | 最终接纳 |
|---|---|---:|---|
| 5.愚蠢人类观察家 | 开始 | −0.00000182 | 是 |
| 5.愚蠢人类观察家 | 中间 | −0.00092501 | 是 |
| 5.愚蠢人类观察家 | 结尾 | 0 | 否 |
| 6.想象在彼方 | 开始 | −0.00030465 | 是 |
| 6.想象在彼方 | 中间 | −0.00002308 | 是 |
| 6.想象在彼方 | 结尾 | −0.00015368 | 是 |

- 6/6 输出有限、声场全局 scale=1（没有为了新降噪触发全混音缩放）。
- 5/6 片段接纳极小降噪差值；1/6 无可信候选，原样返回。
- 所有 guitar/piano 报告 missing_stem，不把缺轨当成功。
- 合成稳态高频噪声、amount=1 时示例测得 −0.833 dB 频带能量变化；掩码最大 5.661 dB，小于 6 dB 上限。
- 测试中的纯音、谐波、镲片式瞬态、短促齿音、音乐包络相关高频未被整体削除；这只证明这些构造例，不保证所有真实镲片/齿音都可识别。

复现工具：`experiments/benchmark_adaptive_noise.py`。输入清单是 `{label,mix,stems}` 数组。每个运行创建新输出目录，拒绝覆盖；结果含来源 SHA-256、代码 SHA-256、参数、前后统一音频指标、阶段统计和试听 WAV。

## 独立代码审计（20260913 收尾）

交付前对 `noise_profile.py` / `soundstage_reshape.py` / 测试做了一轮独立数值审计，结论与处置：

- 核心安全声明经数值复核成立：skip 路径逐位返回输入；delta 代数上等于"降噪后 − 原始"（ISTFT 往返误差 ~1.8e-15）；最坏情况频带衰减恰收敛于 max_attenuation_db 上限；峰值约束保证降噪差值不抬高混音 sample peak；直方图边界安全。
- 联动掩码对左右不相关噪声不保证总能量比严格不变（线性时变算子 ≠ 标量增益），仅对（反）相关声道严格守恒；测试断言按此放宽为 <0.5 dB，`channel_linked` 字段语义不变。
- 已修复：dynamic 模式进度打印谎报静态 side 增益（该模式从不施加），改为如实打印动态门 shelf；旧版 `_spectral_denoise` 对 ≤3072 样本输入的 hop=1 帧数膨胀（内存/时间尖峰），加 3/4 重叠下限，2048/3072 样本回归点入测试。
- 记录不修：掩码统计分位与实际贡献帧范围有 ±2 帧的边缘偏差（仅影响诊断直方图，不影响差值对齐）；`constrain_width_delta` 丢弃输入 delta 的 mid 分量、静音 side 频带不产生新宽度——当前生产路径本就只产生纯 side 增量，属潜在契约，已写入 docstring。
