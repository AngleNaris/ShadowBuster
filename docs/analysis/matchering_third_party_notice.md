# Matchering 第三方来源记录

- 项目：Matchering，作者 Sergree / 上游贡献者。
- 固定版本：2.0.6（Python 包）。
- 来源：https://github.com/sergree/matchering / https://pypi.org/project/matchering/2.0.6/
- 上游许可：GPL-3.0-or-later，完整许可见 https://github.com/sergree/matchering/blob/2.0.6/LICENSE （实际随包许可为准）。
- 本项目通过公共 Python API 调用，未修改或复制其 DSP 实现；候选频谱用于应用自身的受限共同滤波器。
- 依赖包括 numpy、scipy、soundfile、resampy、statsmodels；其各自许可仍适用。

此记录用于追踪来源，不替代发行包中的完整许可证与对应源码安排。项目级许可及组合发行安排尚待发行阶段落实；当前仅完成本地开发验证。
