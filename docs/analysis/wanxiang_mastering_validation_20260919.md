# 万象婆娑真实歌曲母带验证（2026-09-19）

## 范围与素材保护

用户指定目录 `D:/_4.Projects/_MY/万象婆娑`，7 个原始版本（含太虚引 Famle 女声版）。所有源文件只读，测试前后对目录内每个文件的 SHA-256、大小、修改时间及文件清单进行比较，结果完全一致。
所有输出在 `experiments/results/wanxiang_mastering_20260919/`，未写入歌曲目录。测试执行 `tools/probe_album_mastering.py`；音频解释器为 UniverSR/.venv，观测工具 psutil 7.2.2 仅为实验依赖。

每曲取原曲 45% 时间点起的 12 秒，先从真实 48 kHz 转换到 44.1 kHz FLOAT。使用对应 `_shadowbuster.wav` 旧处理成品的同时间片段作为参考，目的仅为功能验证，不视为音质金标准。
每曲 9 个版本：无参考 Neutral/Warm/Bright/Fusion、参考强度 0/25/50/100% + Neutral、参考 50% + Bright，共 63 个片段成品。完整《万象婆娑》（232.4 秒）另做无参考 Neutral、无参考 Bright、参考 50% + Bright，共 66 个成品。
范围是独立母带链；未重新跑 Lew、分轨、低频/人声修复。统一 normal −9.20 LUFS、声场 wet=.6/width=6 dB。

## 核验结果

- 66 个成品均保持预期帧数、44.1 kHz 双声道、PCM24，文件回读通过。
- 所有输出达到 normal 目标的 ±0.2 LU 容差；实际 LUFS 范围 -9.292 至 -9.104。最高真峰值 -0.468 dBTP，低于 −0.4 dBTP 限制。
- 无参考与参考 0% 的最大样本差为 2.384e−7，属于独立 TPDF 抖动差异，未出现参考音色处理。
- 四种用户 EQ 均产生预期变化；参考 50% 时的 Bright 高频提升与无参考时接近，未被参考抵消。
- 每个版本另有 `_equal_loudness.wav`，同组按共同安全响度对齐；回读验证全部 66 个试听文件，最大响度误差 <1e−8 LU，帧数一致。

## 输入对比补充：哪些是改善，哪些是取舍

应纠正此前仅强调达标容易造成的误解：输入本身并未触顶；真峰值约束是在增大响度时防止新增过载，不是修复了已证明存在的削波。下表输入为经过相同 48→44.1 kHz 转换、尚未母带处理的整曲，排除采样率差异；成品均采用测试声场参数。

| 指标 | 输入 | 无参考 Bright | 参考 50% + Bright |
|---|---:|---:|---:|
| 整体响度 LUFS | -14.927 | -9.286 | -9.291 |
| 峰均比 dB | 13.644 | 11.286 | 11.276 |
| 声道相关性 | 0.623 | 0.549 | 0.553 |
| mono 能量变化 dB | -0.906 | -1.109 | -1.099 |
| 触顶样本数 | 0.000 | 0.000 | 0.000 |
| 250 Hz 以上 Side 能量占比 | 23.3% | 29.1% | 29.1% |

可以确认：响度更接近应用目标；声场变宽；EQ/参考按预期改变音色。不能确认：整体保真度、清晰度、细节还原、去噪或失真获得提升。本轮未运行上游 AI 修复，也没有相应的干净真值/失真测量。更亮/更宽/更响不构成普遍音质优势。
动态取舍：整曲峰均比减少 2.37 dB（不是“动态提升”）；参考+Bright 限幅器最大压低约 3.10 dB、95 分位约 1.45 dB。7 个片段的峰均比下降约 0.11–2.82 dB，其中《一烛》最明显。峰均比同时受 EQ/声场影响，不能单独解释为所有瞬态都损失了同样数值。
声场取舍：250 Hz 以上 Side 能量占比由 23.3% 到 29.1%；相关性仍为正，但 mono 总能量损失由约 0.91 到 1.10 dB。它代表适度拓宽及轻微单声道能量代价，不是相位或兼容性的改善。此指标也不等价于局部频段不存在抵消。
参考本身的增量很小：同为 Bright 的整曲，无参考与参考 50% 的 LUFS 差约 0.005、峰均比差约 0.010 dB，宽度占比也几乎一致。主要增量是轻微频谱形状变化；旧处理成品作为参考与原曲本来相近，且共同滤波器有界，听感差别小符合预期。
原有试听包主要比较母带参数版本，并不包含母带输入。已新增 `input_vs_output_full/`：input、off_Neutral、off_Bright、ref_050_Bright 四个整曲 FLOAT 试听文件，统一到输入的 −14.927 LUFS，便于排除响度偏差比较。原始歌曲目录仍未写入。
输入/成品完整对比数据：实验目录 `input_output_comparison.json`。LRA 为应用近似测量、片段仅 12 秒，本次不将其作为标准 EBU LRA 质量结论。
