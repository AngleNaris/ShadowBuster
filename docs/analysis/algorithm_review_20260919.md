## 结果

发现并修复两项可复现问题：

1. GUI 默认的人声空气 +1.5 dB 源自旧 Soren 固定高架衰减补偿，新独立引擎已无这层衰减。现在只有旧 styled 无参考且母带未旁路时保留自动补偿；off、eq_only、用户参考及母带旁路默认 0 dB，显式用户参数仍优先。
2. Lew 旁路原本只检查采样率，44.1 kHz 单声道会一路传到要求双声道的独立母带而报错。现在检查采样率与声道数，必要时在入口统一转换；所有阶段旁路仍保持原始文件字节不变。
