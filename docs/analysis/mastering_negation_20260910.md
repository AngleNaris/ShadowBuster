# 母带环节是否会让上游调整失去意义（2026-09-10）

## 问题

用户调整的低频增强、鼓瞬态、声场宽度等，经过 Soren 母带后还剩多少？母带是否会让上游工作白做？

## 方法

同一首歌（《翻开第四面墙》全曲 198.9 s）、同一套上游参数（Sub +3 dB、Punch +3 dB、饱和 30%、瞬态 30%、宽度 +6 dB、混合 60%、降噪 20%、人声 0、标准重建 1.8）、同一版代码（v1.6.8，Lew FP16），只改变母带模式：

| 组 | 上游 | 母带 |
|---|---|---|
| raw_off | 仅 Lew（旁路 bass/drums/reshape/vocals） | off（透明响度+真峰值） |
| upstream_off | 完整上游 | off |
| upstream_eqonly | 完整上游 | eq_only Bright |
| upstream_styled | 完整上游 | styled Bright / Pop |

输出在 `D:/_4.Projects/_MY/造梦双子星/FINAL/mastering_research_20260910/`，全精度响度用 pyloudnorm 计算，频段比较一律先扣除综合响度差（等响）。原始混音 −7.93 LUFS；soren-off 各组 −9.2；styled −7.59（两者目标不同属正常，等响校正已处理）。

## 代码层面的机制（packaging/soren_original.py / soren_core.py）

styled 模式按顺序执行五层"以参考为目标"的匹配，每一层都可能覆盖上游的调整：

1. **M/S 分别的 RMS 匹配**（`match_rms_ms`）：Mid 与 Side 各自拉到参考 RMS。上游改变的整体响度和整体 Side 能量在这里被归一。
2. **频谱 FIR 匹配**（`match_frequencies_ms`）：对参考/目标的频谱比值做 FIR，**钳制在 Mid ±4 dB、Side ±2 dB**。这是最大的覆盖源：上游任何 ±3 dB 级别的音色调整都在它的作用范围内被重画。注意两点：
   - 合成参考由流派文件**降采样 4 倍**（≈11 kHz）生成，5.5 kHz 以上参考频谱近零，比值饱和到 −4 dB 地板；
   - 代码里的"低频保护"（`bass_preservation`）是**死代码**：它修改的是 `matching_fft`，而 FIR 由 `matching_fft_filtered` 构建，修改被丢弃。
3. **风格 EQ**（v1.6.7 起为真 RBJ 滤波器）在频谱匹配**之后**执行，因此 EQ 本身可以存活。
4. **低通**（`Config.lowpass_cutoff = 18000`，默认开启）：削掉 18 kHz 以上，直接对抗上游重建的高频空气。
5. **电平校正 + 声场定型 + 双级限制器**（`finalize_stereo_image` 只加宽不加窄、上限 +15%；限制器两段 threshold 0.95/0.98、mix 0.95），之后还有 −0.5 dB 峰值归一与 −0.4 dBTP。

## 实测结果

### 上游调整本身到达混音多少（upstream_off − raw_off，等响）

| 频段 Hz | 全频 dB | Mid dB | Side dB |
|---|---:|---:|---:|
| 20–60 | **+0.05** | +0.05 | +0.07 |
| 60–120 | +0.54 | +0.55 | −0.49 |
| 120–250 | −0.21 | −0.16 | −0.92 |
| 12000–16000 | −0.60 | −0.69 | +0.51 |
| 16000–20000 | +0.80 | +0.70 | +2.01 |

Side/Mid 总体 −0.47 dB（低频侧链被自适应收窄，符合设计）。50 ms 峰均比 +0.07；30–180 Hz 起音/尾音比 +0.86 dB。

**关键发现一：Sub +3 dB 在母带之前就几乎不存在了。** 正弦实测 `bass_enhance._shelf`（30 Hz 低通补全式 shelf，filtfilt）：30 Hz 实际 +1.64 dB、40 Hz +0.83 dB、60 Hz +0.21 dB、80 Hz 以上≈0。该 shelf 的转折太低、有效增益不足，经 bass stem 占比稀释后，混音 20–60 Hz 只剩 +0.05 dB。这是**上游设计问题，与母带无关**。Punch 90 Hz 钟形滤波工作正常（90 Hz +3.0 dB），对应 60–120 的 +0.54。

### styled 母带对同一上游产物做了什么（styled − upstream_off，等响）

| 频段 Hz | 全频 dB | Mid dB | Side dB |
|---|---:|---:|---:|
| 20–60 | **−1.90** | −1.90 | −2.90 |
| 60–120 | −0.17 | −0.16 | −1.07 |
| 120–250 | +1.27 | +1.28 | +1.03 |
| 250–500 | +1.51 | +1.41 | +1.88 |
| 1000–2000 | −1.36 | −2.28 | +2.00 |
| 8000–12000 | +1.45 | +1.32 | +3.29 |
| 12000–16000 | +1.38 | +1.13 | +3.60 |
| 16000–20000 | **−1.97** | −2.48 | +1.36 |

Side/Mid +1.87 dB（母带把声场整体加宽，覆盖了声场模块的分频宽度预算）；峰均比 −0.51 dB；综合响度目标 −7.6。

### 存活率（styled 相对上游效应，仅列上游效应 >0.5 dB 的频段）

| 频段 | styled 存活率 |
|---|---:|
| 60–120 | **−0.31**（+0.54 被翻转为 −0.17） |
| 12000–16000 | −2.29（−0.60 被翻转为 +1.38） |
| 16000–20000 | −2.46（+0.80 被翻转为 −1.97） |

负存活率 = 母带按自己的曲线反向重画，不是"削弱 upstream"而是"无视 upstream"。

### 什么活下来了

- **低频起音/尾音（鼓与贝斯的冲击感）几乎完整存活**：上游 +0.86 dB → styled 后 +0.83 dB（96%）。双级限制器（attack 1 ms）没有抹平这首球的低频瞬态。
- **eq_only 模式行为符合 EQ 设计**（2–16 k +0.4～+1.2 dB，低频 ~−0.2 dB），上游调整不被重画，是"保留增强"语义的现成载体。
- 上游的低频侧链接收（Side 60–250 −0.5～−0.9 dB）在 styled 后仍然保持甚至加深。

## 结论

1. **styled 母带确实会让上游的音色与声场调整大范围失效**：频谱匹配按流派参考曲线重画（±4/±2 dB 足够覆盖任何 ±3 dB 级用户调整），18 kHz 低通削空气，Side 匹配与只加宽的声场定型覆盖宽度预算。上游调整在最终成品中的频谱形状，主要由母带决定。
2. **但最大的单项稀释来自上游自身**：Sub +3 dB 因 shelf 设计（30 Hz 转折 + filtfilt 减半 + stem 稀释）在母带之前就只剩 +0.05 dB。母带问题不能掩盖这个上游 bug 级缺陷。
3. **瞬态增强是个例外**：限制器没有抹掉鼓/贝斯起音（96% 存活）。"母带毁弹性"在这首歌上不成立。
4. eq_only（或 off）+ 风格 EQ 的组合是当前架构下"让上游说话"的可行路径；styled 的意义是整体音色统一，但代价是覆盖用户调整。

## 建议（未实施）

1. 重设计 Sub shelf：真 RBJ low-shelf、转折上移（~60–80 Hz）并保证通带增益达标，或在 UI 显示有效频响曲线；这是收益最大、无争议的修复。
2. 让频谱匹配尊重用户意图：把上游各阶段的等效频谱 delta 传给母带，从 FIR 目标中扣除（或对用户明确调整过的频段降低匹配强度）。
3. 删除或修复死代码 `bass_preservation`。
4. 18 kHz 低通默认值改为面向音乐的策略（20 kHz+ 或用户可见开关），至少在 UI 语义中说明。
5. 声场定型考虑接受上游传入的宽度预算，而不是按参考单方面加宽。

## 边界

单一歌曲、Pop/Bright、一组上游参数；瞬态用 30–180 Hz 包络起音/尾音比代理；未做盲听。频段结论表达的是能量分布，不是听感保证。

## 附：建议 1 已实施（2026-09-10 Sub shelf 重设计）

`bass_enhance._shelf` 由"30 Hz 低通补全式"改为**模拟原型 + 双线性变换 + filtfilt 零相位**的真 low-shelf，转折 `SUB_SHELF_FC = 60 Hz`（dB 域半增益中点），单次按 gain_db/2 设计使 filtfilt 总增益精确等于设定值。弃用 RBJ biquad 的原因：该公式在低 fc/小增益组合下失稳（实测 fc=70 Hz/sr=44100/+3 dB 极点半径 1.39）；模拟原型对任意增益极点恒稳定。gain_db=0 精确恒等；主链与饱和预算共用的 `_warm_stage` 同步换用新转折。

正弦实测（+3 dB 设定）：30 Hz +2.82（旧 +1.64）、40 Hz +2.50（旧 +0.83）、50 Hz +2.02（旧 ≈+0.3）、60 Hz +1.50（旧 +0.21）、90 Hz +0.50（旧 +0.04）、120 Hz +0.18（旧 +0.01）。

端到端（同一首歌重跑 upstream_off 与 upstream_styled，输出在 `mastering_research_20260910/subfix_*`）：

- 混音级上游效应：20–60 Hz **+0.05 → +0.20 dB**、60–120 Hz +0.55 → +0.68 dB。方向正确但幅度仍受 delta-add 架构限制：Sub 旋钮只作用于 bass stem，而混音 20–60 能量大头在鼓组（kick），stem 占比决定了上限。
- 新增 sub 能量主要落在侧声道：Side 20–60 从 +0.07 → **+0.81 dB**（bass stem 中的反相低频内容被一并架式提升；声场 reshape 的 LF 守卫只约束 reshape 自己的 delta，不覆盖 bass 阶段已产生的侧链）。建议后续给 bass delta 的低频侧链接入同样的守卫或对 shelf 提升取单声道分量。
- styled 母带叠加后净效应：20–60 Hz 相对基准仍为 −1.79 dB、60–120 Hz +0.42 dB——母带频谱匹配依旧主导低频最终形态，建议 2（让匹配感知上游 delta）仍是更大的杠杆。

测试：全量 374 通过、1 跳过；预算位级回归测试的参照更新为"不含预算路径的同一 DSP 链"（`_warm_stage` 同源），锚定性质不变。

## 附：建议 1b 已实施（2026-09-10 低频侧链受控溢出守卫）

针对上一节发现的"新增 sub 能量主要落到侧声道（Side 20–60 +0.81 dB）"，`bass_enhance` 的立体声路径改为 **M/S 域处理**（`_enhance_stereo`）：Mid 拿全额 sub shelf；Side 的 shelf 增益由 `side_shelf_db()` 给出——按"**Side 新增幅度系数 = Mid 新增幅度系数 × 10^(−6/20)**"定义受控溢出（`SUB_SHELF_SIDE_RELATIVE_DB = −6`），而不是把 shelf 增益平移 −6 dB（平移会把 +3 dB 设定下的 Side 变成衰减，变相单声道化）。**不做黑胶刻盘式完全单声道化**：数字混音的低频保留有限立体声（高相关但非全同），溢出量是设计参数。punch bell / 饱和 / 瞬态对 M、S 用同一参数；门限按 M、S 自身电平计算，近单声道的 S 被门限自然冻结（无侧链内容可放大）。sub_db≤0（削减低频）时 Side 对称同幅削减。

端到端验证（同歌 upstream_off，`subfix2_off` vs 无守卫 `subfix_off`，等响）：

| 指标 | 无守卫 | 守卫版 |
|---|---:|---:|
| Side 20–60 Hz 上游效应 | +0.81 dB | **+0.45 dB** |
| Mid 20–60 Hz 上游效应 | +0.20 dB | +0.19 dB（保留） |
| 全频 20–60 Hz | +0.20 dB | +0.19 dB |
| Side/Mid 总体 | −12.90 dB | −12.86 dB |
| L/R 相关系数 | 0.9025 | 0.9016 |

其余频段效应在 ±0.02 dB 内不变。侧链泄漏约减半且未清零，Mid 提升完整保留——符合"允许受控溢出、不做完全单声道"的目标。测试：全量 377 通过、1 跳过（新增溢出公式数值、M/S 带内增益比、全同输入保持单声道三个回归测试）。

## 附：建议 2 已实施（2026-09-11 母带匹配感知上游意图）

styled 链路的匹配目标从"流派曲线"改为"**流派曲线 × 上游等效频谱 delta**"。实现：

- `studio_backend._upstream_delta_curves`（纯 numpy，外壳无 scipy）：测量母带输入相对**原始管线输入**的 M/S 频谱 delta（含 Lew 重建在内的一切上游处理），1/3 倍频程平滑、限幅 ±9 dB、扣除宽带 rms 比例防二次计入；同时输出 M/S 宽带 rms 比例。经工作目录 JSON 传给 `core_decrypted.py --upstream-delta`；缓存键含内容哈希。
- `soren_original.process_audio`：参考的 M/S 宽带电平按 rms 比例缩放（电平匹配保持上游中/侧平衡，不再抵消宽度意图）；`get_fir` 把形状曲线乘进参考频谱（频谱匹配目标变为流派曲线×意图）。
- 降级策略：delta 计算失败（解码/环境抖动）或上游全旁路时跳过并退回旧匹配，不中止管线；`off`/`eq_only` 路径不受影响。

设计语义：delta 感知输出 ≈ 传统 styled 输出 × 上游意图（谱域）。流派曲线自身的音色仍然生效——用户调整以"相对意图"叠加在风格之上，而不是被抹平。

端到端验证（同一首歌，`delta_styled` vs 旧 `legacy_styled`，等响）：

- 上游意图存活率（净效果/意图，|意图|>0.4 的频段）：60–120 Hz **0.62 → 1.08**（鼓/贝斯 punch 意图完整存活）；2–4k 的匹配行为符合叠加语义；12–16k 为 −1.36（受合成参考 5.5 kHz 带限、FIR ±4/±2 dB 钳制与 18 kHz 低通限制，HF 端只能部分携带，见下"残留边界"）。
- 声场：最终 Side/Mid 由 −10.67 回到 **−11.57**（上游 −12.86）——母带不再把声场单方面吹开，宽度意图被尊重。
- 曲线实测（真实歌曲，121 点）：60–120 Hz mid +0.02、2–4k −1.20、12–16k mid +0.27/side +1.78、16–20k 触及 +9 dB 限幅（Lew 重建的 HF 能量部分被钳制，不会全量注入）。

残留边界（按设计保留）：流派曲线自身的形状（如 Pop 对本曲 1–2k 的 −2 dB 拉伸）依旧生效；±4/±2 dB FIR 钳制、低通、带限参考三个机制在 HF 端限制了负向意图（如降噪减 HF）的携带精度。

测试：全量 381 通过、1 跳过（新增 4 项：曲线计算/一致性、匹配感知正反对照、core 传递、CLI 参数注入）。

## 附：风格强度改为单路径处理强度（2026-09-11）

`style_blend` 最初被实现为完整 styled 湿声与母带前干声的响度对齐末端混合。该方案已废弃：两条路径经历不同 FIR、M/S 与非线性处理后再相加，比例不等于处理深度，并可能产生相位抵消。历史 `version4` 的 Pop 50% 相对无风格输出在活跃短时窗中出现约 −6.12 dB 的高频/主体亮度中位差，属于算法缺陷，不是正常的 Pop 色彩。

当前保留 `style_blend` 这一 API/CLI 名称，但语义是 **0–1 风格处理强度**：

- 输出只走一条信号路径，不再混合完整干、湿波形；强度直接控制参考驱动的 M/S 电平、宽频谱、整体电平、声场与流派动态处理。
- 流派主要通过 linked dynamics 的压缩、瞬态和密度倾向体现。参考频谱 Mid/Side 修正分别限制在小预算内，差分 EQ 也受限，声场只允许有限展宽；显式 EQ profile 独立于风格强度。
- `style_strength=0` 不施加流派处理，但仍走共同的目标 LUFS 与 −0.4 dBTP 收敛；`style_strength=1` 是有边界的完整流派处理，不再与旧版位级一致。
- 频谱匹配只拟合可靠参考带宽内的宽趋势，缺失频带不会被解释为衰减。另约束 4–16 kHz 相对 250 Hz–2 kHz 的最终 FIR 曲线不低于 `−0.35 dB × style_strength`；保护器通过回退过量主体提升实现，不凭空补高频。
- 旁车记录最终 FIR 的 `spectral_*_high_vs_body_db` 和 `spectral_*_darkening_guard_db`，可区分普通流派修正与防发闷保护实际介入。
- `loud` 改为 profile 目标 +2.5 LU，并使用 80 ms 限幅器释放；若动态预算阻止达标，旁车明确记录目标误差与停止原因。

短时暗参考回归同时覆盖 50% 与 100% 强度，不允许活跃窗亮度中位下降超过 0.5 dB、5% 分位下降超过 1 dB。当前全量验证为 409 项通过、1 项跳过、29 项子测试通过。源码修复不会自动更新既有安装目录；必须重新装配运行时并重建安装包后，GUI 才会使用这条链路。
