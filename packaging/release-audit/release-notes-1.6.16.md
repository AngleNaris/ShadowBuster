# ShadowBuster v1.6.16

本版包含自 v1.6.15 以来的实时仪表视图、母带压缩范围控制、P2 级 DSP / 母带升级以及参考音频清除体验优化。

- **实时 DAW 仪表视图**：新增「仪表」页签，监听前采样，提供 Mid / Side / Peak 实时频谱（RTA）、BS.1770 K 加权瞬时/短时响度与峰值表、低/中/高三频段实时极坐标声场动态（填充 + 光滑描边 + 外侧点阵）、左右平衡条以及 20 秒响度走势图；切换音频或版本时保留响度轨迹并标出切源参考线，便于直觉对比不同版本响度差异。
- **母带密度压缩范围**：密度卡片支持原位翻转切换压缩范围，可在「全局」宽带压缩（单台立体声联动 Optical）与低 / 中 / 高分频自由组合之间切换，贯通界面、预设兼容、CLI（`--density-scope`）、缓存和质量报告；鼓起音保护扩展至所有启用密度压缩且含对齐鼓轨的独立母带路径。
- **P2 级母带与分轨 DSP 升级**：
  - **动态共振抑制**：新增立体声联动、上限 2.5 dB 的窄带动态抑制（200–600 Hz 浑浊 / 2–5.5 kHz 刺耳），随母带密度档位联动。
  - **低频偶次谐波饱和与收束**：低频饱和支持非对称 2 次偶次谐波温暖感（保持小信号单位增益与 12 Hz 零相位 DC 阻断）；母带新增温和 12 dB/oct 零相位低频 Side 收束（Mono-Maker，默认 90 Hz，Mid 逐位无损）；常规限幅前增加温和软削峰。
  - **人声清理与前母带低切优化**：新增有界分频人声去齿音（5–9.5 kHz）及 ≥5 kHz 保留谐波的平滑去高频嘶声/电噪；优化无静默段饱满编曲下的自适应低切判定；修正低频一阶平滑系数与 CLI 清晰度授权派生口径。
- **界面与报告细节**：母带参考音频框新增一键清除按钮（并支持聚焦后 `Backspace / Delete` 清除）；报告页新增处理量化明细条，展示限幅压减、软削峰、共振抑制、低频收束、自适应低切与动态余量 PLR。
