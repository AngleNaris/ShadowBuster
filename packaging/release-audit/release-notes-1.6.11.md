# ShadowBuster v1.6.11

本版修复 DSP 音质与测量问题，并补齐安装版的处理脚本、GPU 参考母带依赖和质量报告。

## 更新内容

- 限制持续限幅的活动比例与中位增益衰减，减少强响素材被长期压平的情况；受动态保护限制时，如实报告实际响度低于目标。
- 修复人声压缩、空气补偿之后的伴奏估计与混音重构；零人声增益时，开启的压缩和空气补偿仍正常执行。
- 改善限幅链的过采样滤波，避免少量峰值触发限幅后连带削弱整段高频。
- 低切分析与人声压缩使用声道功率，正确识别 Side 和反相声道中的能量。
- 吉他、合成器和人声后处理使用已清理的工作分轨；缓存命中同时恢复工作分轨，避免覆盖先前降噪和声场处理。
- 修正 K 加权响度回退与 LRA 的计算和门限。
- Windows/macOS 装配包含全部 DSP 脚本及音频工作进程；关键文件校验清单排除会自动重生成的字节码/JIT 缓存。
- 冻结界面的质量报告改由内置音频解释器生成，修复精简外壳缺少 SciPy 时只有音频、没有质量旁车的问题。
- 发布 GPU 环境 **1.6.11**，包含 Matchering 2.0.6 / resampy 0.4.3；旧 1.5.0 包缺少这两项，不能继续作为本版的完整 GPU 环境。
- 包含 v1.6.10 发布后的处理链性能改进和播放器不中断修正。

## 安装与 GPU 更新

关闭旧客户端后覆盖安装 Windows 安装器。安装为 per-user，默认目录为 `%LOCALAPPDATA%\Programs\ShadowBuster`。

使用旧 GPU 环境的用户升级应用后，请在“设置 → GPU 环境”安装 **1.6.11**。更新前应用可使用内置 CPU 运行时完成处理。GPU 资源由客户端按清单下载、校验和安装，不需要手工拼接分卷。

本次发布 Windows 安装器、GPU 清单与三个分卷、`SHA256SUMS.txt`，以及完整项目源码。macOS 装配源码同步修正，未在 macOS 构建新的应用包。

## 验证范围

- 全量回归：**767 passed / 1 skipped / 29 subtests passed**，耗时 146.98 秒。跳过项仅因缺少历史本地实验音频。
- PyInstaller 外壳、CPU/CUDA 运行时从权威源码重新构建；依赖导入、四轨/六轨实际分离及离线模型加载通过。
- 最终安装器在独立目录静默安装通过；安装后的 **28 个权威源码文件**一致，**1,000 个稳定关键文件** SHA-256 复核通过。
- 从最终安装目录运行 EXE，使用真实歌曲的 12 秒片段完成完整 CPU 链及 GPU 用户参考链；两种模式均实际生成质量报告，成品均为 44.1 kHz、双声道、PCM24、529,200 帧，有限值检查通过、采样削波为 0。
- CPU/GPU 16 倍真峰值分别为 **−0.476 / −0.479 dBTP**，低于 −0.4 dBTP 天花板。运行耗时分别为 106.81 / 43.33 秒，代表本机该片段和参数。
- 本轮 DSP 修复另已通过两首完整歌曲的处理、FFmpeg 独立测量和等响片段检查；用户反馈“目前试听感觉正常”。详情见 [DSP 验收报告](../../docs/analysis/dsp_quality_fixes_20261013.md)。
- 报告保留降噪未实际动作、动态预算阻止响度达标等策略提示。未将本轮结果扩展为全部曲风、长曲、最低 16 GB 设备或实时草稿的全面验收。
- 不包含私人音频、处理缓存、`repo.bundle` 或本地实验结果。
