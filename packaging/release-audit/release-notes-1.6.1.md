# ShadowBuster v1.6.1

## 启动修复
- 补齐客户端外壳的 soundfile 与 libsndfile 依赖，修复启动时 No module named soundfile。
- 替代未正式发布的1.6.0候选包。

## 更新
- 母带新增“无风格”，新用户默认选中；保留已保存的用户设置。
- 无风格下 EQ 和响度保持可用：平直为严格响度/峰值处理，其他 EQ 只增加所选 EQ，不进行曲风参考频谱匹配。
- 修正 Lew 快速档显存占用：20秒/1秒重叠改为6秒/0.5秒重叠，标准与精细档不变。RTX5060 Ti 16GB单段30秒测试，峰值张量分配由约12.1GiB降至3.7GiB；不同设备和素材结果不同。
- 更新原曲参考人声平衡、音频输入验证和阶段增益元数据，完善参数单位与传递。
- 同步客户端与DSP脚本，修复部署版本配套问题。

## GPU 环境不需要重新下载
GPU环境未变化，继续复用 [v1.5.0 GPU环境](https://github.com/AngleNaris/ShadowBuster/releases/tag/v1.5.0)（torch 2.7.1+cu128）。本Release不重复上传GPU分卷。
已安装且校验通过的1.5.0 GPU环境继续使用；新安装用户从设置内安装GPU环境，客户端自动查找v1.5.0资源。

## 验证与注意
- 260项测试通过，29项子测试通过；安装到独立目录后依赖导入、文件哈希与新母带路径验证通过。
- 无风格不等于不限幅，较高响度仍可能压缩动态。
- 快速档仍使用原FP32模型，不是量化版；标准/精细档未做8GB显存自适应。
- 发布文件未签名；请核对SHA-256。实验音频及私人分析结果不包含在Release中。
