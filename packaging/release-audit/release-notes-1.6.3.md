# ShadowBuster v1.6.3

## GPU 安装修复
- 修复首次安装 GPU 环境时，Windows 拒绝访问导致已验证的解压目录无法切换为正式环境的问题；重试仍失败时可直接启用已验证目录。
- 重试安装会校验并复用已缓存的环境包和完整解压目录，避免重复下载和解压。
- 已安装且校验通过的 GPU 环境优先本地复用，不需要联网获取清单，也不会因客户端版本升级重新下载。
- 设备探测与环境切换串行执行，避免应用内部并发访问。
- 修复 GPU 设置页检查、下载、取消、重启按钮的状态和隐藏样式。
- 保留已有环境更新失败时的回滚保护。

## 包含此前更新
- 补齐 soundfile / libsndfile 外壳依赖，修复启动缺失模块的问题。
- 母带支持“无风格”，新用户默认选中，EQ 和响度仍可使用，保留已保存设置。
- Lew 快速档改为 6 秒分块、0.5 秒重叠，降低峰值显存需求；仍使用 FP32，标准与精细档不变。

## 安装与 GPU 环境
下载 `ShadowBuster-Setup-1.6.3.exe`，关闭旧客户端后覆盖安装。

GPU 环境版本仍为 **1.5.0**（torch 2.7.1+cu128），未变化、未重复上传。已安装用户直接复用，新用户由客户端获取 [v1.5.0 GPU 资源](https://github.com/AngleNaris/ShadowBuster/releases/tag/v1.5.0)。遇到旧版安装失败的用户，升级后在设置中重试；请保留原缓存与解压目录。

本版替代存在问题的 1.6.0 / 1.6.1 发布及本地 1.6.2 测试包。
