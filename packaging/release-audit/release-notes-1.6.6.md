# ShadowBuster v1.6.6

## 更新内容
- 新增持久处理缓存：按输入文件 MD5、阶段输入及参数复用分轨和其他中间结果，反复调整后段参数时可跳过未变化的前段计算。
- 设置新增缓存容量与已用空间显示，默认 5 GiB，支持关闭、容量限制和二次确认清空；原始歌曲和最终成品不受清空影响。
- 新增可选 Bass「自动清晰」：在低频增强之前进行保守的清晰度 EQ；默认关闭，不保证所有音色均有改善。
- 新增无窗口 CLI：`ShadowBuster.exe --cli`，支持 Agent 调用、JSON 结果报告和 `--no-cache`；默认拒绝覆盖已有成品。
- 母带 `.mastering` / `.mastering.json` 中间报告不再堆积在成品目录；已有历史文件不自动删除。
- 更新硬件风格开关和简明帮助说明，明确软件不提供实时试听或应用内播放。

## 安装
关闭旧客户端后覆盖安装。安装包未签名，请核对 SHA-256。

GPU 环境版本继续使用 **1.5.0**，已有环境复用。本 Release 不重复上传 GPU 环境；新安装由客户端获取 [v1.5.0 GPU 资源](https://github.com/AngleNaris/ShadowBuster/releases/tag/v1.5.0)。

## 验证范围
- 314 项测试通过、1 项跳过、29 项子测试通过；缓存设置和自动清晰开关 JavaScript 测试通过。
- v1.6.6 外壳及安装包重新构建，打包 CLI 版本与 JSON 错误报告检查通过，7 个阶段运行时脚本与源码哈希一致。
- 本轮运行时重新装配，依赖导入及离线 Demucs 短音频分轨检查通过；相同功能的 1.6.5 本地重建包已覆盖安装并启动验证。
- 尚未对 v1.6.6 安装包进行独立安装或整首歌曲端到端验收，未测量真实歌曲的缓存加速幅度。
- 不包含私人音频、缓存、repo.bundle 或本地实验结果。
