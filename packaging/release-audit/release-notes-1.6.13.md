# ShadowBuster v1.6.13

报告页交互与排版清理，仅前端变更；音频处理算法与 v1.6.12 相同。

## 变更内容

- 频率响应曲线视野固定为 20 Hz–20 kHz，移除滚轮缩放、拖拽平移与双击复位；悬停读数保留。
- 频谱变化区只保留淡入淡出：换视图 240ms、换版本 240ms、位图异步到达 260ms；移除左右擦除与旧位图叠化。
- 修复首次进入报告页时真实频谱被占位提示盖回的问题：频谱位图不再登记入场重放钩子。
- 报告页移除顶部信息行（文件名、格式胶囊、图例、分析时间）与四张摘要 KPI 卡，页面从频率响应曲线直接开始。
- 播放器到第一张图的间距收到 **12px**，与报告内卡片间距一致。
- 静态资源版本 `style.css?v=96`、`app.js?v=91`，旧缓存立即失效。
- 构建校验修正：`verify_gui.ps1` 在 `Start-Process` 重定向启动时可能取不到退出码，改为以冒烟报告是否生成且 `status=pass` 为准；能取到退出码时仍要求为 0。

## 升级

关闭客户端后覆盖安装。本版应用版本为 **1.6.13**，GPU 环境继续使用 **1.6.11**；已安装 GPU 1.6.11 的用户无需重新下载。旧 GPU 1.5.0 的用户仍需在设置中安装 GPU 1.6.11。

本次发布 Windows 安装器、校验文件和源码。macOS 未构建新应用包。

## 验证

- 全量回归：**761 passed / 11 skipped / 29 subtests passed**，121.82 秒。
- 外壳重建通过：PyInstaller onedir、QML/翻译裁剪、numpy 检查。
- 冻结 GUI 检查通过：Qt 6.11.2，429 个界面元素（移除信息行与 KPI 卡后较 1.6.12 的 439 个减少 10 个），页面加载完成、QWebChannel 桥接就绪，应用/桥接版本均为 1.6.13。
- 静默安装到独立目录通过：安装器退出码 0，安装目录 GUI 检查通过；安装后的 runtime 导入探针通过（torch/demucs/look2hear/matchering/resampy/mastering 等，numpy 2.5.2）。
- 浏览器实测报告页：首元素为图表面板，无信息行/KPI 残留；播放器到首卡与卡片间距均为 12px；四张图与频谱视图切换正常，无控制台错误。
