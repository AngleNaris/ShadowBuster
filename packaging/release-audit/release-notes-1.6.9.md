# ShadowBuster v1.6.9

## 更新内容
- 重构母带风格强度：保留 `style_blend` 参数名以兼容 GUI、CLI 与缓存，但数值现在直接控制单路径风格处理力度，不再把两条经过不同相位、频谱与动态处理的完整波形做末端干湿混合，消除 50% 等中间比例可能产生的抵消与发闷。
- 流派母带改为以压缩、瞬态与密度性格为主；参考驱动的 M/S 电平、宽频谱和声场修正使用小预算，保留高频、低频/鼓、人声与声场等上游处理对最终成品的影响。显式 EQ profile 独立于风格强度。
- 修复流派参考采样率/有效带宽解释；缺失高频不再被当作衰减目标。增加相对暗化保护：4–16 kHz 相对 250 Hz–2 kHz 的最终 FIR 倾斜不低于 `−0.35 dB × 风格强度`，通过回退过量主体提升实现，不凭空补高频。
- `loud` 改为 profile 目标 +2.5 LU，并将该档限制器释放收紧到 80 ms。无风格、仅 EQ 与风格化母带共用 LUFS/真峰值收敛；动态预算阻止安全达标时，旁车报告实际响度、误差和停止原因。
- 母带 `.mastering.json` 旁车增加处理强度、各阶段校正、动态/限制器预算、最终高频相对主体倾斜和暗化保护回退量。Soren 源码内容进入阶段缓存身份，升级后仅母带阶段失效，上游缓存仍可复用。
- 界面“风格强度”帮助文字同步为处理强度语义，明确它不是干湿波形比例。

## 安装
关闭旧客户端后覆盖安装。安装包未签名，请核对 SHA-256。安装器为 per-user，默认安装到 `%LOCALAPPDATA%\Programs\ShadowBuster`，无需管理员权限；历史装在 Program Files 的 per-machine 版本不会自动卸载，需先手动卸载旧版或在安装向导中明确选择目标目录。

GPU 环境版本继续使用 **1.5.0**，已有环境复用。本 Release 不重复上传 GPU 环境；新安装由客户端获取 [v1.5.0 GPU 资源](https://github.com/AngleNaris/ShadowBuster/releases/tag/v1.5.0)。

## 验证范围
- 源码全量回归：409 项通过、1 项跳过、29 项子测试通过；母带与 staged-source 重点回归 35 项通过；开发 Soren 运行时与 canonical 源码校验通过。
- 最终实歌直母带的 Pop50/Pop100 活跃窗亮度中位分别为 +0.043/+0.096 dB，5% 分位为 −0.152/−0.290 dB；完整流水线 Pop50 + Bright 相对 eq_only + Bright 为中位 +0.113 dB、5% 分位 −0.118 dB，高频瞬态中位 +0.154 dB。50% 亮度曲线相对 0%/100% 的中点误差中位 0.0047 dB，未复现旧版发闷或相消。
- 直母带 off/Pop50/Pop100 分别为 −6.769/−6.764/−6.776 LUFS，完整流水线 Pop50 为 −6.776 LUFS；4× 近似真峰值均不高于 −0.4 dBTP。自动指标用于排除结构性缺陷，不替代人工听音验收。
- 三步构建全部重跑：PyInstaller 外壳、CPU 运行时装配、Inno 安装器。运行时真实导入 OK（torch 2.7.1+cpu）；`critical-manifest.sha256` 已纳入 `soren_original.py`。
- `install_test.ps1 -Version 1.6.9` 静默安装通过；安装后 13 个依赖导入探针通过（numpy 2.5.2），975 个 manifest 文件全部复验一致。已安装 Soren core/DSP 与 canonical 源码哈希相同，GUI 帮助文字和 `ShadowBuster.exe --cli --version`（1.6.9）通过。
- 历史 `version4` Pop 50% 成品经活跃短时窗复测，高频相对主体亮度中位下降约 6.12 dB；该文件只作为旧算法缺陷证据，未被覆盖。
- GPU 环境包未改动、未重建、未上传，继续使用 1.5.0。既有流派模型在 sklearn 1.9.0 下会报告由 1.5.1 序列化的版本警告，本次加载与处理成功。
- 不包含私人音频、缓存、`repo.bundle` 或本地实验结果。
