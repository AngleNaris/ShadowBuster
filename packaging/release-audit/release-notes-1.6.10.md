# ShadowBuster v1.6.10

## 更新内容
- **宽度旋钮语义修订（授权增长）**：0–100% 授权比例直接授权新增 Side 的能量增长（100% = +12dB Side 增益），废除 reshape 与独立母带两层的固定增长阶梯（旧阶梯在默认档位就封顶，向上调整无响应）；单声道兼容占比上限放宽并成为唯一固定保护（120–300Hz 0.40、300–2k 0.60、2k–8k 0.75、8k+ 0.70，全局 0.70）。120Hz 以下不生成宽度、鼓攻击段收紧、变窄回退保护不变。
- **试听饱和度对齐正式链路**：草稿 DSP 饱和项改为与 `bass_enhance.soft_clip(drive=1.6)` 同形（小信号增益 1.74），试听与导出的低频提升与谐波特征一致；试听宽度去掉旧 0.4 硬盖（默认档即饱和的死区），全程单调响应。
- **移除内置流派选择**：参考曲目受版权约束无法分发，风格只来自用户参考音频；参考音频入口移入母带面板，响度改为与 EQ 风格一致的分段组件，母带面板两行与声场面板行位逐像素对齐。无参考即无风格母带（off/eq_only）。
- **采样器式参数预设（9 槽）**：输出目录右侧固定 9 个方形槽位，均分占满整行；左键空槽保存当前面板参数（含面板 bypass 开关，不含路径类设置）、左键已存槽一键应用、右键进入待确认（✕）后再右键移除或左键覆盖，4 秒未确认自动取消；空槽凹陷/已存点亮/待确认反色的拟物质感。参数持久化快照升版 v2（宽度 dB → 授权比例自动迁移）。
- **修复主题切换后声场扇形颜色不跟随**：改为监听主题模块的 `sb-theme` 同步事件直接重画一帧，不再依赖动画帧（窗口被遮挡/节流时旧 rAF 路径会停在旧主题色的最后一帧）。
- 试听播放器与正式导出的参数语义保持一致；宽度/声场/饱和的试听近似与导出预算同步修订。

## 安装
关闭旧客户端后覆盖安装。安装包未签名，请核对 SHA-256。安装器为 per-user，默认安装到 `%LOCALAPPDATA%\Programs\ShadowBuster`，无需管理员权限；历史装在 Program Files 的 per-machine 版本不会自动卸载，需先手动卸载旧版或在安装向导中明确选择目标目录。

GPU 环境版本继续使用 **1.5.0**，已有环境复用。本 Release 不重复上传 GPU 环境；新安装由客户端获取 [v1.5.0 GPU 资源](https://github.com/AngleNaris/ShadowBuster/releases/tag/v1.5.0)。

- 源码全量回归：695 项通过、11 项跳过、29 项子测试通过（宽度授权语义、UI 预设槽位、母带面板对齐、试听 DSP 合同为本次新增/修订项）。
- 宽度语义数值验证：默认档（50%）典型素材 Side 兑现约 +4dB（旧版 +2–3dB 且到顶）；12dB 请求在窄素材上兑现至占比上限；`constrain_width_delta` 新增 `growth_db` 授权参数并通过越界校验测试。
- 试听 DSP 契约（Node）：默认以上宽度仍有响应（满档 ≈ 3× 半档）、默认饱和可闻、预设参数实时同步、流式连续性、Δ 监听与循环节回归通过。

- `install_test.ps1 -Version 1.6.10` 静默安装通过（EXIT=0）；安装后运行时依赖导入探针通过（numpy 2.5.2）。
- GPU 环境包未改动、未重建、未上传，继续使用 1.5.0。
- 不包含私人音频、缓存、`repo.bundle` 或本地实验结果。
