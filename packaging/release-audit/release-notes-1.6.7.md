# ShadowBuster v1.6.7

## 更新内容
- 声场重塑新增自适应宽度控制：120 Hz 以下低频不再被拓宽，避免整体浑浊；分频段设置能量占比与增长上限；鼓瞬态（起音）降低拓宽、尾音与混响允许有限拓宽；总量保留 UI 滑杆控制。
- 贝斯饱和新增低中频预算：180–500 Hz 饱和增量按原曲低中频密度自动收敛，最多衰减 3 dB，全曲单一静态因子，不引入动态抽吸；自动清晰仍默认关闭。
- 母带 EQ 语义重做：Bright/Warm/Fusion 改用真实 RBJ 高架/峰形滤波器，修复旧 Bright 平行结构在 9–10 kHz 的实际衰减；Bright 现按含义提升 Mid/Side 高频，并移除旧的 500–600 Hz 中央提升。
- 开发工作流统一：新增 `tools/make_dev_runtime.py`，开发态 Soren 运行时由打包权威源生成并哈希校验，不再直接执行外部旧 DSP 目录；处理缓存指纹包含运行时清单，算法变更后旧缓存自动失效。
- `runtime_sync.ps1` 打包源与校验同步更新；补充声场/贝斯/EQ 语义、开发运行时的回归测试与分析文档。

## 实测对比（同一首歌曲，等响度）
- 新版相对旧处理版：12–16 kHz +3.5 dB、8–12 kHz +2.0 dB，中央声像高频同向增加；1–4 kHz −2.2 至 −3.3 dB。
- 声场收敛：Side/Mid 由 −8.6 dB 回到 −10.7 dB（原版 −12.0 dB）；60–120 Hz 相对旧版 +2.6 dB。
- 相同参数（Rock/精细重建/宽度 +6 dB/混合 80%）试听反馈改善明显；详见 `docs/analysis/` 下 2026-09-09 分析文档。
