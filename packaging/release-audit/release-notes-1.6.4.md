# ShadowBuster v1.6.4

## 母带行为恢复
- 有风格母带恢复 Soren 原版处理链，撤掉自加的 1.5 dB 限幅驱动预算及相关风格处理干预，恢复原版限幅、峰值归一化和默认 18 kHz 低通。
- 进入有风格母带前验证输入有效性；超峰时仅整段、双声道同步衰减，不额外压缩或调整人声。
- 无风格及其 EQ 路径保持不变。
- 原版 loud 沿用原版增益行为，不承诺精确命中固定 LUFS。

## 错误信息复制
- 错误弹窗新增“复制错误信息”，位于“知道了”左侧；两按钮等宽，整组占底部内容区一半宽度。
- 复制完整错误摘要、产物目录和详细日志，提供成功与失败反馈，不关闭弹窗。

## 安装
关闭旧客户端后覆盖安装。本次正式包替代此前本地 1.6.4 测试包，版本号仍为 1.6.4。

GPU 环境版本仍为 **1.5.0**，已安装环境继续复用，不重复下载。本 Release 不上传 GPU 环境；新安装由客户端获取 [v1.5.0 GPU 资源](https://github.com/AngleNaris/ShadowBuster/releases/tag/v1.5.0)。

## 验证
- 270 项测试、29 项子测试通过；错误复制与 GPU 界面状态测试通过。
- 最终包已独立安装并验证启动；母带核心、界面资源与源码逐字节核对，原生复制接口已包含。
- 原版核心一致性测试通过；此前同一母带代码已通过 CPU 和复用 GPU 解释器的歌曲处理验证。
- 安装包未签名，请核对 SHA-256。私人音频和实验结果不包含在发布内容中。
